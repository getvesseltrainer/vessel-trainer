How to use them

  1. From the game Press F4, then Structures, Online library, Refresh the list. Pick a structure and Download structure.
  2. Or from this site Download the file into .minecraft/config/vesseltrainer/structures, then Reload structures.
  3. Place it Aim at a block and use Preview at aimed block, then Place at aimed block. Undo takes it all back.

Structures

Banners

For the top of the menu. In the game: Settings, Banner library, then Download and use. From the site, put the file in .minecraft/config/vesseltrainer/banners.

A banner

An image for the top of the menu, still or animated.

Share a banner

Sharing needs a free GitHub account. Your image is public as soon as you send it, and it joins the library once it has been reviewed. PNG up to 4096 pixels wide, shrunk to 1280 for the game, or GIF up to 600 pixels. 10 MB at most.

  • Command blocks are never placed, and a structure that has any cannot be shared.
  • Text that runs a command when clicked blocks sharing too.
  • Only import files from people you trust.
